# Synhawk

**Synhawk** is an AI cybersecurity platform focused on real-time detection of deepfake voice and video attacks.

We build detection systems for:

* Voice calls
* Video communication
* Asynchronous media (audio, video, text)

Our mission is to protect digital communication from synthetic identity fraud.
